# 煙神楽（ENKAGURA）公式サイト

黒に近い焦げ茶・生成り・金を基調にした、1ページ構成の静的サイトです。外部ライブラリを使わず、HTML・CSS・必要最低限のJavaScriptだけで動作します。

## ファイル構成

```text
煙神楽HP/
├─ index.html       ページの文章と全セクション
├─ assets/
│  └─ favicon.svg   ブラウザタブ用の仮マーク
├─ css/
│  └─ style.css     デザインとレスポンシブ対応
└─ js/
   └─ main.js       メニュー・表示演出・FAQ
```

## 現在「公開準備中」にしている情報

- 正式な住所、最寄駅、営業時間、定休日
- 料金システムと各メニュー価格
- シーシャ、ドリンク、ボトル、VIPの正式メニュー
- 予約URL、Instagram、LINE、電話番号
- 年齢制限、支払い方法、ドレスコードなどの正式な利用条件
- ロゴデータと実店舗写真

確定前の情報を誤って公開しないため、これらは `index.html` 内で明確な仮表示にしています。

ブラウザタブの「煙」マークも正式ロゴ受領後に差し替えます。

## 写真を入れる場所

写真はまだプロジェクト内にないため、現在はCSSで作った仮ビジュアルを表示しています。写真を受け取ったら `images` フォルダを作り、次の順で差し替えます。

1. ヒーロー（ファーストビュー）の店舗象徴写真
2. CONCEPTの店内写真
3. SPACEの店舗全体、シーシャと酒、細部、VIPルーム

## 手元で確認する方法

`index.html` をブラウザで開くだけでも確認できます。公開前にはローカルサーバーで表示し、PC幅・スマートフォン幅・メニュー操作・FAQ操作を再確認します。
