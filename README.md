# 煙神楽（ENKAGURA）公式サイト

黒に近い焦げ茶・生成り・金を基調にした、1ページ構成の静的サイトです。外部ライブラリを使わず、HTML・CSS・必要最低限のJavaScriptだけで動作します。

## ファイル構成

```text
煙神楽HP/
├─ index.html       ページの文章と全セクション
├─ assets/
│  └─ favicon.svg   旧仮マーク（現在は正式ロゴを使用）
├─ css/
│  └─ style.css     デザインとレスポンシブ対応
├─ images/
│  ├─ enkagura-logo.png  正式ロゴ
│  ├─ top-01.png    ヒーロー・店舗全体のイメージビジュアル
│  ├─ top-02.png    入口のイメージビジュアル
│  ├─ top-03.png    シーシャと酒のイメージビジュアル
│  └─ top-04.png    VIPルームのイメージビジュアル
└─ js/
   └─ main.js       メニュー・表示演出・FAQ
```

## 現在「公開準備中」にしている情報

- 正式な住所、新宿駅からの徒歩時間
- 料金の税込・税別、ドリンク注文などの詳細条件
- フレーバー、ドリンク、ボトル、VIPの正式メニューと価格
- 予約URL、Instagram、LINE、電話番号
- 実店舗写真

確定前の情報を誤って公開しないため、これらは `index.html` 内で明確な仮表示にしています。

正式ロゴは、ヘッダー・ヒーロー・フッター・ブラウザタブ・SNS共有画像へ反映済みです。

## 現在反映済みの店舗情報

- 営業時間：18:00〜06:00
- 定休日：水曜日
- 最寄駅：新宿駅（徒歩時間確認中）
- チャージ：19:59まで2,000円、20:00以降3,000円
- シーシャ：ショート1時間3,000円、レギュラー1.5時間4,000円、スペシャル2時間5,000円
- 延長：2時間以降、30分につき1,000円
- 支払い：現金、各種クレジットカード、電子決済、QRコード決済
- 年齢制限：20歳以上
- ドレスコード：なし

## 画像の掲載状況

`images` フォルダ内の4枚を、煙神楽の世界観を表す「イメージビジュアル」として掲載しています。

1. `top-01.png`：ヒーロー、SPACEの店舗全体
2. `top-02.png`：CONCEPT、SPACEの入口
3. `top-03.png`：SPACEのシーシャと酒
4. `top-04.png`：SPACEのVIPルーム

実店舗写真が準備できたら、同じ場所へ順次差し替えます。

## 手元で確認する方法

`index.html` をブラウザで開くだけでも確認できます。公開前にはローカルサーバーで表示し、PC幅・スマートフォン幅・メニュー操作・FAQ操作を再確認します。
